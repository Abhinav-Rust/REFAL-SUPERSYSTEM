These are source editions added on 4 November 2026 while assessing REFAL-SUPERSYSTEM against Valentin Turchin's computational and philosophical work. There are **nine files covering eight works**: six PDFs, two official web texts, and the English TeX source of an article also supplied in Russian translation.

The downloaded files retain their original bytes. [sources.json](sources.json) records authors, source and resolved URLs, retrieval times, SHA-256 hashes, file sizes, languages, edition notes, and PDF page counts. The [retrieval script](fetch_sources.py) makes the source list reproducible. The existing collection has been preserved.

Running `python3 docs/turchin/recovered/fetch_sources.py` from the repository root retrieves local copies and verifies their recorded hashes. Python 3, `pdfinfo`, and `pdftotext` are required. Downloaded publications and text extractions are a local cache; the catalog, provenance, and downloader are versioned. Searchable PDF extractions are written to `text/`. They are convenience copies produced by `pdftotext -layout`, and some contain broken ligatures or mathematical symbols. Refer to the PDFs when quoting. The scanned metavariables report has no text sidecar because extraction produced only page separators. The English epistemology file is directly readable as TeX source.

The older thematic collection is valuable as a bibliography and guide to subjects, but its HTML expositions must not automatically be treated as verbatim primary publications. In particular:

- The older *Phenomenon of Science* exposition's chapter outline differs from the authentic book. The book's first chapter is “The Initial Stages of Evolution,” and chapter 9 is “Mathematics Before the Greeks.” Different page counts alone would not establish an error because editions vary; the chapter-content mismatch is the stronger evidence.
- The alleged 1991 *A Supersystem of Language Refal* report and its exact “four concentric rings” description have **not been authenticated against an original publication** in this audit. This is an unresolved attribution, not a claim that the report cannot exist. A useful contemporary design can be proposed without presenting an unverified reconstruction as Turchin's exact architecture.
- Repository statements that a quotation was checked against an HTML file from the older collection do not, by themselves, establish that it was checked against a primary text.
- The actual 1996 self-application paper describes flat Refal, pattern-matching graphs, and metasystem jumps as its three innovations. Architectural claims should be traced to these actual texts, with edition and page references.

The attempted retrieval of the 1980 Courant monograph produced an incomplete PDF. It is **not included in this source index or counted as a recovered original**. The failed download is retained only among the assessment's retrieval artifacts.
