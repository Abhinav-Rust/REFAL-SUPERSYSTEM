## The runtime row closes — a block sentence carrying a condition (this session)

The work list did not cover one case: a **block sentence carrying conditions**
fell back to the recursive evaluator. The cause was two-fold and the second was
the one that mattered — `terms_are_worklist_safe` returned `false` for such a

shares the one handler. **Gate, non-vacuous:** 100,000 block-conditioned steps

finish against the fix. Corpus unchanged (`differential-corpus: equal`, 72).

## E-11's accumulator: the constructor-entering partition folds it (no stack configuration needed)

**The recorded measurement reproduced exactly:** `Rev { () (e.A) = (e.A); (t.H
e.T) (e.A) = <Rev (e.T) (t.H e.A)>; }` from `Go { e.X = <Rev e.X ()>; }` →
`visited: S0`, no whistles, three splits, `Rev` residual at **residual-work 37**.

**The row's stated reason for withholding is refuted.** It does *not* need a
two-level stack configuration: `residualize-driven examples/accumulator-reverse.ref
--split pattern` → **residual-work 9**, `Rev` **eliminated**, artifact
`Go { e.Input = <Split1 e.Input ()>; }` + `Split1` = the callee's own two
sentences. The sequence partition peels the argument list's **tail** and never
enters `(e.B)`; the pattern partition partitions the bracket's **contents** by
the callee's own patterns.

**Built:** `--split sequence|pattern` on `drive-symbolic` / `residualize-driven`
(default `sequence`); `drive_entry_configuration_with_split` and
`residualize_entry_graph_with_split` in `refal-core`. Gate
`the_pattern_partition_folds_a_nested_accumulator` (pins the gap, the fold, and
**runs** the artifact against the source).

## The pattern partition is ported into `compiler.ref` — a differential

**The partition rides in the strategy character**, so the driver state's 14
fields are untouched (threading a 15th is what would turn the six byte-identity
gates red). Lowercase = constructor-entering: `DsSplit` dispatches on it,
`DsInterpretive` accepts `'i'`, `DsStratName`/`DsOtherName` map both cases,
`DsStratC (e.M)`/`DsStratI (e.M)` give the search its two characters. Modes:
`RESIDUALIZE-DRIVEN-PATTERN` (search), `…-COMPILATIVE`, `…-INTERPRETIVE`.

**The mechanism that folds the accumulator:** a split is identified by the
**sentences it emits**, so `<Rev (e.T) (t.H e.A)>` (reached while driving
`Split1`'s second branch) reuses `Split1` instead of making `Split2`.
`DsAddSplitWith` registers the branches *before* the drive — the Rust does the
same — storing them in the split record's 4th field, which `DsSetSents` later
replaces; `DsSentsMatch` compares either form.

**Refal gotchas that cost time (avoid next time):**
- An extra pair of brackets in a *term* pattern. A BR term is `(BR <contents>)`,
  so the pattern is `(BR e.X)`; a VAR term is `(VAR s.K e.N)`. Writing
  `((BR …))` / `((VAR …))` silently matches nothing and surfaces as "no sentence
  matched".
- `SameChars` takes two *bracketed* lists: `<SameChars (s.K) (s.K2)>`.
- A variable's name is the same across kind prefixes: `s.P` and `t.P` collide.
- `<` nesting must be counted: `DsRdRunP` needed five `>`, not four.
- `DsRdEmit` needs a sentence per mode; a new mode that is not `(REPORT)`/`(PLAIN)`/
  `(SEED n)` fails with "no sentence matched in DsRdEmit".

**Coverage, measured:** **52 of 77** examples agree byte for byte (`compiler.ref`
excluded). The 25 that diverge need the two unported halves. Gate
`the_pattern_partition_is_ported_to_the_refal_authored_driver` — sweeps the
corpus, requires `accumulator-reverse` to fold and the count not to fall below 52
(a non-regression gate, because agreement everywhere would need the unported
halves). **Figure unchanged.**
