## The runtime row closes — a block sentence carrying a condition (this session)

The work list did not cover one case: a **block sentence carrying conditions**
fell back to the recursive evaluator. The cause was two-fold and the second was
the one that mattered — `terms_are_worklist_safe` returned `false` for such a
block, so *every function whose result contained one* left the work list too.
With `DEFAULT_MAX_CALL_DEPTH = usize::MAX`, a recursion through one ran on the
host stack unguarded.

**Fix:** `ConditionEval` now carries a `ConditionOwner` (`Function` or `Block`),
so a failing chain continues into the right next sentence via
`owner.next_sentence`; the `Block` handler mirrors the `Function` handler, which
shares the one handler. **Gate, non-vacuous:** 100,000 block-conditioned steps
abort with `STATUS_STACK_OVERFLOW` against the old `terms_are_worklist_safe`, and
finish against the fix. Corpus unchanged (`differential-corpus: equal`, 72).
