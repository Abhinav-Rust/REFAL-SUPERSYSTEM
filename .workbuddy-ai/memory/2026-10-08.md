## Shipped: E-11's negative half (approved by the Chief Architect)

Commit `597300e` on `main`.

**The finding that shaped the design.** `examples/compiler.ref` implements only
the **sequence** partition (`DsSplit` / `DsExprVarPos`). The pattern partition
(`SplitStrategy::Pattern`) exists in `refal-core` alone and is projection-only —
the compiler must keep the sequence partition or the six Refal-vs-Rust
byte-identity gates move. So "implement it in refal-core and
examples/compiler.ref together" has no Refal half here: the pairing discipline is
satisfied by the byte-identity gate, which is the strongest possible statement
(the change cannot reach the default path at all).

**What was built.** `pattern_split_configuration` used to *decline* when a
callee's component at the split position is a bare variable, because the branch
it would produce *is* the configuration and driving it folds back to the split
(`Split7 { (e.Rest) t.P e.In = <Split7 (e.Rest) t.P e.In>; }`). It now emits that
sentence as the **complement** branch: Refal's ordered sentences express
`e.X != ('A')` with no negation operator, and the body is the sentence's own
result taken verbatim, so the configuration is never re-entered. The callee is
**eliminated** instead of left residual.

Measured: `F { ('A') = 'a'; e.Other = 'z'; }` → one split,
`Split1 { ('A') = 'a'; e.Other = 'z'; }`, `F` gone. Residue agrees with the
source on `A`, `B`, `Q`.

Guards (all sound, all deliberate):
- withheld when the sentence has a condition (the fall-through cannot be
  reproduced by a branch with no conditions);
- withheld when the pattern *before* the split position binds a variable the
  complement's body would need (`term_has_variable`);
- withheld entirely when *every* sentence is a bare variable — nothing for the
  complement to be the complement *of*. This is why
  `a_bare_variable_at_the_split_position_is_declined_rather_than_looped` still
  passes unchanged.

Gates: `the_partition_carries_the_complement_of_its_definite_branches`
(refal-core, 72/72) and
`the_partition_emits_the_complement_branch_and_the_callee_disappears` (refal-cli,
which *runs* the artifact against the source). New fixture
`examples/projection-complement.ref` — note it uses a **character** bracket
`('A')`, not an identifier, because `refal run` passes an argument as a bracket of
its characters; that is what makes the artifact drivable from the CLI.

Verified: fast gate unchanged (`differential-corpus: equal`, 72 cases);
`cargo fmt --check` clean; `cargo clippy -p refal-core --all-targets` clean.

## Shipped: the stack-configuration boundary, measured (E-11's last item)

Commit `772fc84` on `main`.

**Measuring first narrowed the gap, and the narrowing is the finding.** The
missing stack configuration is *not* "non-tail recursion" in general. A non-tail
recursion whose context is a bracket folds when the callee **names the bracket
case explicitly**, and whistles into a residual call when a single `t.` variable
covers the symbol and bracket cases together — which is how a Refal programmer
would naturally write it.

| `Rev` | Residue |
|---|---|
| `{ = ; s.H e.T = <Rev e.T> s.H; (e.B) e.T = <Rev e.T> (e.B); }` | **folds** — `(e.B1) e.T1 = <Split1 e.T1> (e.B1)`; `Rev` eliminated; 7 steps, **0 whistles**, residual-work 6 |
| `{ = ; t.H e.T = <Rev e.T> t.H; }` | **whistles at the bracket branch** — `(e.B1) e.T1 = <Rev (e.B1) e.T1>`; `Rev` carried into the residue; 6 steps, 1 whistle, residual-work 10 |

Both residues are **correct**; the merged form loses only the fold.

**The mechanism.** The explicit form's bracket branch reduces to
`<Rev e.T1> (e.B1)`, whose recursive call *is* the split's own configuration and
so folds to `<Split1 e.T1>`. The merged form's walk whistles at the branch
*before* that reduction. The divergence is on the `t.`-variable-binding-a-bracket
path.

**Entry point for the next session.** The cause is in `DriveContext`'s
`visited_inputs` / whistle path (`crates/refal-core/src/lib.rs`, the recurrence
checks around the sentence loop — `record_whistle` at ~:1546, the checks at
~:1709-1750), **mirrored as `DsWhistle*` in `examples/compiler.ref`**. Any fix
there moves the compiler's residues, so it is a **paired** change: Rust and the
Refal counterpart must land together, or the six byte-identity gates go red.

Gated in both directions by
`a_non_tail_recursion_folds_only_when_the_bracket_case_is_named` (`refal-cli`) —
the day the fold lands, the second half fails and says so.

## Shipped: the whistle fix — E-11's non-tail half closed (approved)

Commits `53a0012` (the fix) and `bb88d96` (a figure correction) on `main`.

**The fix is one line, and it was a matcher defect rather than a missing stack
machine.** `term_homeomorphic_embeds` returned `true` for *any* variable, so a
`s.` variable was treated as embedding into a bracket — impossible, since `s.`
binds a symbol and a bracket is never a symbol.

**Why it lost folds.** The sequence partition splits `e.X` into
`[]` / `s.H e.T` / `(e.B) e.T` — two non-empty branches that are **disjoint cases
of the same variable**, neither a growth of the other. When one sentence's pattern
covers both (a `t.` or `e.` variable at the split position) the branches reach the
**same state**, so the `visited_inputs` embedding test compares them against each
other; the symbol branch then looked like a growth of the bracket branch, the
whistle fired, and the configuration was left residual.

**Measured.**
- `F { t.H e.T = 'ok'; }` + free argument: bracket branch was `<F (e.B1) e.T1>`,
  now `'ok'`.

  was 1 whistle / residual-work 10 / `Rev` retained → now 0 whistles /
