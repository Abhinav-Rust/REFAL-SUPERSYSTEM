## Session 3 — the 100% definition corrected, and E-11's design space mapped

**The question the Chief Architect asked.** Turchin's 1980 §5.8 Theorem 5.1 says
no algorithm turns every graph of states into an equivalent perfect graph. Is
that a 1980-technology limit, or does 2026 change it?

**Answer: the theorem stands, and it is not a technology limit.** It is proved by
modelling formal arithmetic in Refal and reducing to Church's theorem — the same
class as the undecidability of the halting problem. Better hardware, tooling and
ML do not move a computability bound. Live confirmation: the Termination
Competition still runs annually as a *semi-decision* benchmark.

**But the row was mis-described, and that was fixed.** The theorem forbids a
*universal decision procedure*, not a *sound, incomplete* one. The Tier-1 row
withholds credit for "no termination analysis", which reads as impossible; it is
really withholding a **sound, incomplete, certificate-carrying feasibility
analysis** — prove what you can, emit a checkable witness, localise the rest as
an explicit `unproven` set. SMT (Z3/cvc5 over decidable fragments), size-change /
ranking-function termination provers, and proof assistants make that practical in
2026 and not in 1980. **Consequence: target stays 100%; no row reclassified; no
figure moved.** Committed `fa42fad`. Docs: README gains "What Theorem 5.1 does and
does not forbid", conformance doc gains §8, PROGRESS restates the definition.

**E-11 design space mapped (committed `4a5d78c`, in PROGRESS).** Four candidate
fixes tried/reasoned through; all fail:
1. relax the single-variable guard → residue has `e.Program` unbound (wrong).
2. prefer the leftmost free var inside a bracket → regresses (`e.T2` splits again).
3. component-plus-free-tail partition → incomplete: `e.Program = (End) (In)` is
   legal for `<Run e.Program e.Input>` because `(End) e.In` absorbs it.
4. stop-when-no-progress → sound, but a homeomorphic guard also fires on
   `compiler.ref`'s `Dispatch`, which makes *real* progress → differential gates
   would go red.

**Conclusion:** the partition must be **pattern-driven** (partition the component
by the callee's sentence-pattern shapes at that position, complement fails where
the source fails, splits under the whistle). One design, not four patches. This
is also the first instance of the certificate-carrying analysis the Tier-1 row
now asks for.

**Next session — the concrete Stage 1.** Implement the pattern-driven partition

## Session 8 — the 2nd projection EMITS TARGET CODE (`d9903ee`) — E-14 credit 3.50

**Delivered.** `refal run examples/compiler.ref SPECIALISE "<template>" "<program>"`
→ the **target program** for that object program. Verified:
`(Times ('*' '*' '*') (Seq (Lit 'a' (End)) (In)))` →
`e.Input = 'a' e.Input 'a' e.Input 'a' e.Input;` — **identical to `refal metasystem`'s
residue** for the same program. residual-work 0.

**The design (the whole trick).** The object program travels through the **SOURCE**,
not the driver: the interpreter carries a token where its program belongs
(`Go { e.In = <Run MARKER e.In>; }`), `DsSpecialise` lexes both, splices the
program's tokens in place of the marker, and drives the spliced source. **Nothing on
the driver's ten-function chain is touched**, so the default path is unchanged *by
construction* — confirmed by `compile_command_compiles_the_compiler_itself` (377 s)
and the corpus sweep (73 s). This is why the source-splicing route beat the
threading.

**Three defects, all fixed (Refal gotchas worth remembering):**
1. `(<Lex ...>)` is **rejected** — a call may not be bracketed in place. Bracket via
   a function that *returns* a bracket term (`Bracket1 { e.X = (e.X); }`).
2. A missing `>` on `LexSource` — `<Lex ... <StripCR ...> e.Source>>;` needs two.
3. **An identifier token's word is a bracket of CHAR LITERALS** (`(Ident 'M' 'A' …)`),
   **not** `SYM` terms. `IsMarker { ('M' 'A' 'R' 'K' 'E' 'R') = '1'; … }`. Getting
   this wrong makes the splice *silently* do nothing.

**Gate.** `the_generator_emits_target_code_that_runs` — feeds the emitted target 3
inputs and requires agreement with `examples/metasystem-unroll.ref` (same interpreter,
same program hardcoded → independent reference). Fixture:
`examples/specialise-template.ref`.

**Figure ~89% → ~90%; E-14 credit 2.50 → 3.50.** Withheld: the *derivation* — this is
an authored mode that applies the driver, not a residue of `S(S, int)`.

**Also answered for the Chief Architect:** "can we remove Rust?" — **No, and it is not
incubation scaffolding.** The *compiler* is self-hosted (Refal→Refal) ✓, but a
compiler is a program and needs a **machine** to run it (L0 = Rust). Self-hosting the
machine still bottoms out in a substrate; a native backend would make the compiler
emit C, not Refal. And Rust is the **differential oracle** — Turchin: the new level
*controls* the old, it does not replace it. What *can* shrink is the CLI's Rust
surface (check/lints/formats could delegate to the Refal-authored checker).
