### Step 2 — Tier-1 feasibility + termination with certificates — done

- New module `crates/refal-semantics/src/feasibility.rs`; new CLI command
  `refal feasibility <file.ref> [--certificate]`.
- Per sentence: `feasible` (ground witness, re-checked) / `infeasible`
  (shadowing proof) / `unproven` (named). Per function: `Descends {sentence,
  from, to}` / `NonRecursive` / `Unproven {reason}`.
- Soundness rule that is load-bearing: a descent run must be a **proper
  contiguous run** with a **non-`e.` term outside it** — otherwise
  `F { e.X e.Y = <F e.X>; }` would be wrongly proved.
- `verify()` re-checks every claim; `--certificate` runs it and exits non-zero
  on failure. **The checker found a real defect**: the descent run belongs to a
  sentence, not the function, so the verdict now carries the sentence index.
- **Measured: 0 infeasible across the 77 non-`bad-*` examples**; compiler.ref
  1.9 s, 90 unproven sentences, 129 unproven functions.
